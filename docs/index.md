# Бот для психо- и нейролингвистических экспериментов

Telegram-бот, в котором лингвист собирает экспериментальную сессию
из готовых шаблонов (lexical decision, cloze, AJT, SPR, maze, probe
recognition, picture selection, covered box, forced choice, sentence
repetition, video task и др.) или конструирует свой сценарий в режиме
free-form, раздаёт ссылку информантам и потом выгружает данные в CSV
(с приложением голосовых записей в виде zip-архива).

Документация состоит из двух разделов:

- **[Руководство для исследователя](researchers.md)** — как
  зарегистрироваться, создать эксперимент, загрузить стимулы и
  медиафайлы, опубликовать ссылку и забрать данные. Для каждого
  шаблона приведены формат CSV, пример заполнения и описание того,
  что попадает в выгрузку.
- **[Руководство для разработчика](developers.md)** — карта
  репозитория, описание каждого модуля и его публичных функций,
  правила добавления нового шаблона эксперимента, схема MongoDB,
  условия деплоя.

## Что покрывает бот

- 17 шаблонов стандартных парадигм + конструктор free-form;
- демография (стандартная анкета, своя CSV-анкета, отказ);
- распределение участников по листам (A/B/C…), рандомизация
  порядка стимулов и позиций кнопок/картинок;
- тайм-аут на ответ, idle-таймаут на сессию, повтор прохождения;
- кастомные тексты инструкций, лейблов кнопок и шкалы Ликерта;
- предпросмотр эксперимента для исследователя без попадания в
  итоговые данные;
- экспорт в CSV + zip с голосовыми записями;
- промо-рассылка прошлым информантам.

## Технологии

Python 3, aiogram (FSM, роутеры, middlewares), MongoDB через Motor,
GridFS для бинарных данных (голосовые ответы, картинки-стимулы).
Развёртывание — локально (Windows) или на удалённом сервере;
конфигурация через `.env` (токен бота, строка подключения к MongoDB,
имя БД).

## Контекст

Работа выполнена как ВКР на ОП «Фундаментальная и компьютерная
лингвистика», НИУ ВШЭ, 2026. Идея — дать лингвистам инструмент, в
котором стандартные экспериментальные парадигмы доступны как готовые
шаблоны: исследователь загружает CSV со стимулами и медиафайлы,
настраивает параметры, получает ссылку для информантов, потом
выгружает данные в CSV.
